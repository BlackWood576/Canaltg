# TG-бот: редактор канала по performance marketing

Бот раз в день (или дважды) собирает свежие темы из RSS рекламных блогов и профильных СМИ,
просит Gemini выбрать одну лучшую и написать пост на русском и английском, и присылает
готовый черновик **тебе в личку**. Ты жмёшь «Опубликовать» — и пост уходит в канал.
Без твоего одобрения в канал ничего не попадает.

Всё работает бесплатно: генерация — на бесплатном тарифе Gemini, запуск по расписанию —
на бесплатном GitHub Actions.

---

## Что понадобится (один раз, ~20 минут)

### 1. Telegram-бот
1. Открой в Telegram **@BotFather** → команда `/newbot`.
2. Придумай имя и username. BotFather выдаст **токен** вида `123456:ABC-DEF...` — это `TG_BOT_TOKEN`.
3. Добавь этого бота **в свой канал администратором** с правом публикации сообщений.

### 2. Твой личный chat_id (куда придут черновики)
1. Напиши что-нибудь своему новому боту в личку (пару слов).
2. Открой в браузере (подставив токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найди в ответе `"from":{"id":123456789 ...` — это число и есть твой **`TG_ADMIN_ID`**.

### 3. Имя канала
`TG_CHANNEL` — это `@имя_твоего_канала` (публичный) либо числовой id вида `-100...` (приватный).

### 4. Ключ Gemini (бесплатно)
1. Зайди на **aistudio.google.com/apikey** под своим Google-аккаунтом.
2. Нажми «Create API key». Скопируй — это `GEMINI_API_KEY`.

## Как запустить на GitHub (бесплатно)

1. Создай на GitHub **новый приватный репозиторий** и загрузи туда все файлы из этой папки
   (`bot.py`, `requirements.txt`, папку `.github`).
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
   Добавь четыре секрета:
   - `GEMINI_API_KEY`
   - `TG_BOT_TOKEN`
   - `TG_ADMIN_ID`
   - `TG_CHANNEL`
3. Вкладка **Actions** → включи workflow → нажми **Run workflow**, чтобы проверить прямо сейчас.
4. Дальше он будет запускаться сам по расписанию из файла `.github/workflows/bot.yml`.

### Как это работает по времени
- Расписание стоит на 07:00 и 15:00 UTC. Бельцы летом = UTC+3, то есть 10:00 и 18:00 по местному.
  Поменять можно в `bot.yml` (строки `cron`).
- При запуске бот сначала проверяет, не одобрил ли ты прошлый черновик кнопкой, и если да —
  публикует его в канал. Потом собирает новые темы и присылает новый черновик.
- Значит: нажал «Опубликовать» — пост уйдёт в канал при **следующем** запуске
  (в пределах нескольких часов). Это плата за полностью бесплатную схему.

## Настройки, которые ты можешь менять сам

- **Источники тем** — список `RSS_FEEDS` в начале `bot.py`. Добавляй/убирай ленты.
- **Частота** — строки `cron` в `.github/workflows/bot.yml`.
- **Модель** — переменная `GEMINI_MODEL` (по умолчанию `gemini-2.0-flash`).
- **Стиль/отбор** — текст `EDITOR_PROMPT` в `bot.py`. Это и есть твой промт; правь под себя.

## Про картинки
На старте бот делает только текст — бесплатной генерации изображений под эту связку
практически нет. Картинки пока добавляй вручную перед публикацией, либо позже подключим
платный image-API за копейки.

## Частые вопросы
- **Бот молчит.** Проверь, что все 4 секрета заданы и бот — админ канала. Загляни в логи:
  вкладка Actions → последний запуск.
- **Черновик пришёл, а в канал не публикует.** Убедись, что бот админ именно в канале
  и что `TG_CHANNEL` указан правильно (`@...` или `-100...`).
- **Хочу больше/меньше постов.** Меняй расписание в `bot.yml` и/или число источников.
